# Component Tutorial Notebooks

These notebooks accompany the component examples in
`pioneerml_example_plugin.components_tutorial_examples`.

- `00_overview.ipynb`: project theme and bundled sample data
- `01_build_custom_components.ipynb`: registered component tour
- `02_pipeline_config.ipynb`: JSON config wiring
- `03_run_training_pipeline.ipynb`: small training/evaluation/export run with plots
- `04_generate_pipeline_config.ipynb`: build the full config from editable Python blocks
- `05_run_inference_pipeline.ipynb`: small inference run with JSONL predictions and a plot
